BDD(Behaviour Driven Development) Write tests that describe how the app BEHAVES, in language that anyone — developer, tester, or client — can read and understand.

Traditional testing thinks like this:
    "Test that the login function returns true when credentials match"

BDD thinks like this:
    "GIVEN a registered user
    WHEN they enter correct credentials
    THEN they should be welcomed into the app"

Real World Examples Before Code
    ATM Machine:
    GIVEN  I have $500 in my account
    WHEN   I withdraw $100
    THEN   my balance should be $400

TO RUN :- npx playwright test tests/BDD --project=chromium
TO VIEW RESULT :- npx playwright show-report
